## 🚀 Key Production Patterns (Learned)

### 1. Tool Calling is Mandatory
- Always Tools API, not Functions API (deprecated)
- T=0.0 + JSON Schema + allowlist + regex + strict True = 99.9% valid JSON
- Parallel when independent (50% latency cut), sequential when dependent

### 2. Dynamic Temperature
- Planning T=0.7 (creative diverse), Reasoning T=0.4 (balanced), Tool calling T=0.0 (deterministic 99.9% valid) - 80% steps
- Loop breaking T=0.7 breaks 90% loops vs 10% at T=0.0
- Writing T=0.7 friendly vs T=0.0 robotic

### 3. Sampling Controls
- Temperature shapes (peaky vs flat), Top-k fixed keeps k tokens, Top-p adaptive keeps cumulative p, Constrained Decoding masks invalid
- Pipeline: Logits -> T -> Softmax -> Top-k -> Top-p -> Constrained Mask -> Sample
- Tool calling: T=0.0 + Top-p=1.0 + Top-k=None + JSON Schema = 99.9% valid

### 4. Trees for Complex Reasoning
- Chain (ReAct) 1x cost 70% success for simple FAQ
- Tree (ToT) k=3 beam=2 3x cost 85-90% success for complex reasoning
- MCTS iterations=50 50x cost 90-95% success for coding/game
- Behavior Tree 0.1x cost 99% deterministic for policy enforcement (mandatory for amount>500)

### 5. GraphRAG for Multi-Hop
- Vector RAG fails 40% enterprise QA because 1-hop only
- GraphRAG: KG extraction + Leiden community detection + Hybrid retrieval (vector + graph traversal 2-3 hops + community search) + auditable path
- 60% -> 85% accuracy on multi-hop (+25%), 40% -> 75% on global QA
- Build $102 vs $1 for 10K chunks (100x), query $0.03 vs $0.01 (3x)

### 6. State Management
- LangGraph with Postgres checkpointer for resume, time-travel
- Serialize state waiting_approval before webhook, resume after
- Conversation tree with parent_id + branch_id, not linear array
